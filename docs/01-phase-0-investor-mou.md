# Phase 0 — ආයෝජකයා සමඟ එකඟතාව | Investor Agreement & MOU (බණ්ඩාරවෙල ආයෝජකයා)

> **ඇයි මෙය Phase 0 වන්නේ:** සමාගම ලියාපදිංචි කරන්නට **පෙර** ආයෝජකයා සමඟ කොන්දේසි ලිඛිතව තහවුරු නොකළහොත්, පසුව ඇතිවන ආරවුල් කර්මාන්ත ශාලාවම නවත්වයි. මෙය නීතිමය ලියාපදිංචියක් නොවේ — නමුත් **සියල්ලටම පෙර අවශ්‍යම ලේඛන**.
> Why this comes first: an unwritten investor understanding is the single biggest cause of stalled projects. These are not registrations — they are the foundation documents.

## 0.1 — ආයෝජක පරීක්ෂණයට අවශ්‍ය ලේඛන | Documents to collect from the Bandarawela investor

|---|---|---|
| I1 | **NIC පිටපත** (දෙපැත්ත) හෝ විදේශික නම් **Passport** + visa/residence proof | අනන්‍යතාව; eROC Form 18 සඳහා |
| I2 | **ලිපිනය තහවුරු කිරීම** — විදුලි/ජල බිල්පතක් හෝ Grama Niladhari සහතිකය | ලියාපදිංචි ලිපිනය |
| I3 | **මූල්‍ය හැකියාවේ සාක්ෂි / Proof of funds** — බැංකු අයවැය ප්‍රකාශයක් (bank statement, මාස 3–6), Fixed Deposit සහතික, හෝ බැංකු නිර්දේශ ලිපියක් | ආයෝජනය සැබෑද? |
| I4 | **Bank Reference Letter** | විශ්වසනීයත්වය |
| I5 | **Tax clearance / TIN** (ආයෝජකයාගේ පෞද්ගලික) | බදු අනුකූලතාව |
| I6 | **ඉඩම් හිමිකම් විස්තර** — ආයෝජකයා බණ්ඩාරවෙල ඉඩමක් දරන්නේ නම්: ඔප්පුව, සමීක්ෂණ සැලැස්ම, උකස් තත්ත්වය | ඉඩම ආයෝජනයක් නම් **අනිවාර්යයි** |
| I7 | **Encumbrance Certificate (උකස් සහතිකය)** | ඉඩම උකස් කර ඇත්ද? — Divisional Registrar කාර්යාලයෙන් |
| I8 | **Rate payment receipt** (ප්‍රා.ස./නගර සභා බදු ගෙවා ඇති බව) | ඉඩම් බදු |
| I9 | **වෙනත් ව්‍යාපාර හිමිකම් විස්තර** | ගැටුම් (conflict of interest) |
| I10 | **Criminal record / Police report** (විශාල ආයෝජනයක් නම් නිර්දේශිත) | Risk |

> **ඔබද මෙම ලේඛනම ආයෝජකයාට ලබා දිය යුතුය.** දෙපාර්ශ්වයම එකම තොරතුරු හෙළි කිරීමෙන් trust ගොඩනැගේ. 👉 [Phase 15 — Due Diligence Pack](15-investor-due-diligence-pack.md)

## 0.2 — අනිවාර්ය ගිවිසුම් 3 | The 3 must-have agreements

### 📄 1. NDA — රහස්‍යතා ගිවිසුම (Non-Disclosure Agreement)
ව්‍යාපාර සැලැස්ම, ජල පරීක්ෂණ වාර්තා, යන්ත්‍ර quotation, පාරිභෝගික ලැයිස්තු බෙදාගැනීමට **පෙර** අත්සන් කරන්න.
**කාලය:** දින 1–2. **වියදම:** නීතිඥ ගාස්තු LKR 15,000–40,000.

### 📄 2. MOU / Term Sheet — අන්‍යෝන්‍ය අවබෝධතා පත්‍රය
නීතිමය බැඳීමක් නැති (non-binding) නමුත් පහත දේ ලිඛිත කරයි:

| කොන්දේසිය / Term | පැහැදිලි කිරීම / What to specify |
|---|---|
| **මුළු ආයෝජනය** | LKR ___ — කොටස් මිලදී ගැනීමද? ණයක්ද (shareholder loan)? මිශ්‍රද? |
| **කොටස් අනුපාතය** | ඔබ ___% / ආයෝජකයා ___% |
| **ගෙවීමේ කාලසටහන** | Tranches — කවදා, කුමන milestone එකට |
| **ආයෝජනයේ ස්වභාවය** | Equity vs Loan vs Convertible — **ඉතා වැදගත්** |
| **ඉඩම දායකත්වය** | ආයෝජකයා ඉඩම ලබා දෙන්නේ නම් — ඒ සඳහා කොටස් % කොපමණද? ඉඩම සමාගමට හරවා දෙන්නේද නැතහොත් බදු දෙන්නේද? |
| **කළමනාකරණ පාලනය** | අධ්‍යක්ෂ මණ්ඩලයේ ආසන, Managing Director කවුද?, ආයෝජකයාගේ veto අයිති |
| **Reserved matters** | ආයෝජක අනුමැතිය අවශ්‍ය තීරණ ලැයිස්තුව |
| **Dividend policy** | ලාභයෙන් කොපමණක් බෙදා හරිනවාද |
| **Exit / Buy-out** | ආයෝජකයා පිටවන්නේ කෙසේද? Valuation ක්‍රමය? |
| **Non-compete** | වසර ___ ක් |
| **Conditions Precedent** | අත්සන් කිරීමට පෙර සපුරාලිය යුතු කොන්දේසි (උදා: ජල පරීක්ෂණ වාර්තාව SLS 614 සමත් වීම) |

👉 සූදානම් ආකෘතිය: [`templates/01-MOU-term-sheet.md`](../templates/01-MOU-term-sheet.md)

### 📄 3. Shareholders Agreement (SHA) — නීතිමය බැඳීම සහිත
සමාගම ලියාපදිංචි කළ **දිනයේම** අත්සන් කළ යුතුය. AoA එකටත් වඩා විස්තරාත්මකයි.

## 0.3 — ව්‍යාපෘති වාර්තා (පෙර-ලියාපදිංචි) | Pre-registration project documents

| # | ලේඛනය | ඇයි අවශ්‍යද | වියදම (LKR) |
|---|---|---|---|
| P1 | **Feasibility Study / Business Plan** | ආයෝජකයාට + බැංකු ණයට + BOI ට | 75,000 – 400,000 (consultant) |
| P2 | **භූ විද්‍යාත්මක සමීක්ෂණය / Hydrogeological survey** | ජලය තිබේද? කොපමණද? — **මුදල් යෙදවීමට පෙරම කළ යුතු දෙය** | 150,000 – 600,000 |
| P3 | **වෙළඳපොළ පර්යේෂණය** | උඩරට/බණ්ඩාරවෙල ප්‍රදේශයේ ඉල්ලුම, තරඟකරුවන්, මිල | 50,000 – 200,000 |
| P4 | **Financial Model (වසර 5)** | IRR, Payback, Break-even, Cash flow | P1 හි ඇතුළත් |
| P5 | **Land title report** (නීතිඥ වාර්තාව) | ඉඩම පිරිසිදුද? | 25,000 – 75,000 |
| P6 | **Preliminary plant layout sketch** | FCAU අයදුම්පතට + UDA permit එකට | 50,000 – 150,000 |

> 💡 **ඉතා වැදගත්:** P2 (ජල සමීක්ෂණය) සහ P5 (ඉඩම් title report) **නොකර** MOU එක නීතිමය වශයෙන් බැඳෙන ලෙස අත්සන් **නොකරන්න**. MOU එකේ *Conditions Precedent* ලෙස මේවා ඇතුළත් කරන්න.

## 0.4 — ආයෝජකයාට පෙන්වීමට සූදානම් කරගන්න | Investor pitch pack

1. Executive Summary (පිටු 2)
2. වෙළඳපොළ අවස්ථාව — උඩරට බෝතල් ජල ඉල්ලුම
3. ජල මූලාශ්‍ර වාර්තාව (hydrogeology + ආරම්භක පරීක්ෂණ)
4. යන්ත්‍රෝපකරණ quotation (වෙළඳුන් 3කගෙන්)
5. Financial model (5 years, 3 scenarios)
6. Regulatory roadmap (මෙම ලේඛනයේ Phase 1–10)
7. අවදානම් විශ්ලේෂණය 👉 [Risk Register](16-risk-register.md)
8. කණ්ඩායම සහ CVs
