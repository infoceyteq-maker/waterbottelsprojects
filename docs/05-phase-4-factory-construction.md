# Phase 4 — කර්මාන්ත ශාලා ඉදිකිරීම | Factory Construction & Food-Grade Layout

> SLSI audit එකේදී හා FCAU inspection එකේදී **වැඩිපුරම පරීක්ෂා වන්නේ ගොඩනැඟිල්ලේ සැලසුමයි.** වැරදි සැලසුමක් නිසා audit අසමත් වීම = මාස 6–12 ක ප්‍රමාදයක්.
> The layout is where most SLSI/FCAU audits fail. Design it right the first time.

## 4.2 — FCAU/SLSI විසින් බලාපොරොත්තු වන ඉදිකිරීම් අයිතම | Construction items audited

### 🔵 බිම් සහ බිත්ති / Floors & walls
- [ ] **ආහාර ශ්‍රේණියේ බිම් (food-grade flooring)** — epoxy හෝ acid-resistant tiles, **ජලය බැසයාමට තරංග ආනතිය (1:80 slope)**
- [ ] බිත්ති — **අවම වශයෙන් 2 m උසින්** smooth, washable, non-absorbent tiles/paint
- [ ] කෙළවර (wall–floor junctions) — **coved/curved**, කෙළවර 90° නොවිය යුතුය
- [ ] වහල — condensate නොවැටෙන ලෙස; **drop ceiling** නිර්දේශිත
- [ ] ජනේල — **වසා දැමිය හැකි, කීට පටල (insect screens)**, කඩා වැටුණොත් ආරක්ෂිත වීදුරු (shatterproof film)
- [ ] දොරවල් — **self-closing**, air curtains / PVC strips, කීට පටල

### 🔵 වාතාශ්‍රය / Air & ventilation
- [ ] Filling room — **positive air pressure**, HEPA/filtration (Class 100,000 / ISO 8)
- [ ] **Air locks / man-locks** නිෂ්පාදන ප්‍රදේශයට ප්‍රවේශයේදී
- [ ] උෂ්ණත්ව/ආර්ද්‍රතා පාලනය (air conditioning/dehumidification)
- [ ] වාතය ගලා යාම **පිරිසිදු ප්‍රදේශයේ සිට අපිරිසිදු ප්‍රදේශය දෙසට**

### 🔵 සනීපාරක්ෂක පහසුකම් / Hygiene facilities
- [ ] **Hand wash basins** — **අත් ස්පර්ශ නොකරන (knee/elbow/sensor operated)**, සබන්, sanitiser, කඩදාසි
- [ ] **Footbath / boot wash** ප්‍රවේශයේදී
- [ ] වෙනස් කරන කාමර + lockers + වැඩ ඇඳුම් (vending)
- [ ] **වැසිකිළි** — නිෂ්පාදන ප්‍රදේශයට **සෘජුව විවෘත නොවන**; සේවක 25 දෙනෙකුට ~1ක්; අත් සෝදන පහසුකම් ඇතුළතම
- [ ] පානීය ජල පහසුකම් (සේවකයන් සඳහා)

### 🔵 පාලන පද්ධති / Control systems
- [ ] **Pest control** — වාර්ෂික ගිවිසුමක්, rodent bait stations, UV insect traps, තිර (screens)
- [ ] **Waste management** — වෙන් වූ කසල බඳුන් (පෙදල සහිත), කසල ගබඩා කිරීමේ ප්‍රදේශය
- [ ] **Effluent Treatment Plant (ETP)** හෝ soakaway + grease trap — CEA ප්‍රමිතියට
- [ ] **ජල පරීක්ෂණාගාරය (QC Lab)** — pH, TDS, turbidity, conductivity, ozone residual, microbial
- [ ] **CIP (Clean-in-Place)** පද්ධතිය
- [ ] ආලෝකය — ආරක්ෂිත fittings, අවම 220 lux (නිෂ්පාදන ප්‍රදේශය)
- [ ] **ආරක්ෂාව** — fire extinguishers (CO₂/dry powder), fire exits (අවම 2ක්), emergency lighting, first aid, safety signage
- [ ] **CCTV** (නිර්දේශිත) + visitor log + access control

### 🔵 උපයෝගිතා / Utilities
| උපයෝගිතාව | අවශ්‍යතාව |
|---|---|
| විදුලිය | **3-phase**; සම්පූර්ණ ධාරිතාව + 30% margin |
| Backup generator | සම්පූර්ණ බරේ 60–80% (RO + blow moulding) |
| Water supply | ළිඳ + අතිරේක tank (දින 2–3 ක සංචිතය) |
| Compressed air | **Oil-free / food-grade air compressor** — blow moulding සහ filling සඳහා |
| Chilled water | RO membrane + filling උෂ්ණත්ව පාලනය |
| Steam/boiler | Shrink wrapping / sterilisation |
| Drainage | වෙන් වූ process / sanitary / storm drainage |

## 4.3 — ඉදිකිරීම් ලේඛන | Construction-phase documents

| # | ලේඛනය | කවුරුන් |
|---|---|---|
| C1 | **Approved architectural drawings** (floor plan, elevations, sections) | Chartered Architect |
| C2 | **Structural drawings + calculation report** | Chartered Structural Engineer |
| C3 | **M&E drawings** (electrical, plumbing, drainage) | Chartered Mechanical/Electrical Engineer |
| C4 | **Process flow diagram + P&ID** | Process engineer / plant supplier |
| C5 | **Cleanroom specification & layout** | Plant supplier / cleanroom contractor |
| C6 | **Bill of Quantities (BOQ)** | Quantity Surveyor |
| C7 | **Contractor agreement + insurance** | Contractor + ඔබේ නීතිඥ |
| C8 | **Construction progress reports / site diary** | Contractor |
| C9 | **Material test certificates** (tiles, epoxy, SS pipe grade certificates) | Suppliers |
| C10 | **Commissioning report** | Plant supplier |
| C11 | **As-built drawings** — FCAU අයදුම්පතට අවශ්‍යයි | Architect |
| C12 | **Certificate of Conformity (CoC)** | UDA / ප්‍රා.ස. |

## 4.4 — FCAU අයදුම්පතට විශේෂයෙන් අවශ්‍ය සැලසුම් 4 | The 4 drawings FCAU specifically asks for

| සැලැස්ම / Drawing | විස්තරය |
|---|---|
| **1. Location Map** | කර්මාන්ත ශාලාවේ **Google Map** පිහිටීම |
| **2. Site Plan** | **සමීක්ෂණ සැලැස්මේ පිටපතක් මත ජල මූලාශ්‍රය සහ කර්මාන්ත ශාලාව සලකුණු කර** |
| **3. Factory Layout** | **ප්‍රාදේශීය බලධාරියගේ අනුමත ගොඩනැඟිලි සැලැස්ම** |
| **4. Sketch Map of Source Water & Processing Facility** | මූලාශ්‍රයේ සිට බෝතල් කිරීම දක්වා **සියලු උපාංග සහිත** සවිස්තර සිතියම |
| **5. Process Flow Chart** | නිෂ්පාදන ක්‍රියාවලියේ flow diagram |

> 🔴 මේ 5ම FCAU අයදුම්පත සමඟ **අනිවාර්යයි**. ඉදිකිරීම් අවධියේදීම මේවා සූදානම් කරගන්න.
