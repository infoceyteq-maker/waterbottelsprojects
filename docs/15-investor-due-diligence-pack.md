# ආයෝජක Due Diligence පැකේජය | Investor Due Diligence Pack

> ආයෝජකයා (සහ ඔබ) මුදල් යෙදවීමට **පෙර** මෙම ලේඛන සියල්ල පරීක්ෂා කළ යුතුය. ආයෝජකයා වෘත්තීය මට්ටමින් මෙය ඉල්ලා සිටිනු ඇත — **පෙර සූදානම් වීමෙන් විශ්වාසය ගොඩනැගේ.**

---

## 15.1 — Due Diligence කොටස් 6

### 📁 A. නීතිමය / Legal DD
- [ ] ඉඩම් ඔප්පුව + වසර 30 root of title + නීතිඥ වාර්තාව
- [ ] Encumbrance certificate (උකස් නැති බව)
- [ ] සමීක්ෂණ සැලැස්ම (පර්චස් 160+)
- [ ] Zoning confirmation (කර්මාන්ත භාවිතයට අවසර)
- [ ] Street line certificate
- [ ] ඉඩම ආයෝජකයාගේ නම් — **contribution එකට ගණනය කරන වටිනාකම සහ ක්‍රමය** (independent valuation)
- [ ] සමාගමේ Certificate of Incorporation, Form 1, AoA
- [ ] Shareholders Agreement + MOU
- [ ] සියලු ගිවිසුම් (contractors, suppliers, distributors)
- [ ] නඩු/විවාද තත්ත්වය (litigation search)

### 📁 B. තාක්ෂණික / Technical DD
- [ ] **Hydrogeological survey report** — ජල ප්‍රමාණය, ගුණාත්මකභාවය
- [ ] **SLS 614:2013 මූලාශ්‍ර ජල පරීක්ෂණ වාර්තා** — 🔴 **වඩාත්ම වැදගත් ලේඛනය**
- [ ] Yield / pumping test report
- [ ] Soil test report
- [ ] Flood / drainage assessment
- [ ] සමීක්ෂණ සැලැස්ම + process flow diagram
- [ ] යන්ත්‍ර quotation 3 + සැපයුම්කරු වාර්තා (references, track record)
- [ ] Utility capacity confirmation (විදුලි, ජල)

### 📁 C. මූල්‍ය / Financial DD
- [ ] Feasibility study + financial model (වසර 5)
- [ ] CAPEX breakdown (quotation මත පදනම්)
- [ ] OPEX + unit economics
- [ ] Break-even + payback + IRR + sensitivity analysis
- [ ] Working capital plan
- [ ] මුදල් සැපයුම් සැලැස්ම (equity/debt split)
- [ ] ආයෝජකයාගේ **proof of funds** + bank reference
- [ ] ඔබේ proof of funds / asset contribution

### 📁 D. නියාමන / Regulatory DD
- [ ] **නියාමන මාර්ග සිතියම** (මෙම පැකේජයේ Phase 1–10)
- [ ] සියලු ලබාගත් බලපත්‍ර / අනුමැති + කාලසටහන්
- [ ] WRB ලියාපදිංචි තත්ත්වය
- [ ] CEA EPL වර්ගීකරණය
- [ ] FCAU ලියාපදිංචි තත්ත්වය
- [ ] SLSI සහතික තත්ත්වය
- [ ] **Regulatory risk assessment** — කුමක් අසමත් වුවහොත් කුමක් සිදුවේද?

### 📁 E. වෙළඳපොළ / Market DD
- [ ] වෙළඳපොළ පර්යේෂණ වාර්තාව
- [ ] තරඟකාරී විශ්ලේෂණය (උඩරට බ්‍රෑන්ඩ් + මිල)
- [ ] ඉලක්ක වෙළඳපොළ + පරිමාව
- [ ] Distribution plan + ලැබී ඇති commitments
- [ ] Pricing strategy + margin structure

### 📁 F. මෙහෙයුම් / Operational DD
- [ ] Org chart + key personnel CVs
- [ ] පුහුණු සැලැස්ම
- [ ] සැපයුම් දාමය (preforms, caps, labels) — backup suppliers
- [ ] Quality management plan
- [ ] **Risk register** 👉 [Phase 16](16-risk-register.md)
- [ ] Insurance plan

## 15.3 — ආයෝජක ගිවිසුමේ අනිවාර්ය ආරක්ෂණ | Protections to negotiate

### ආයෝජකයා ඉල්ලනු ඇත:
- Board seat(s)
- **Reserved matters** — veto on: capital expenditure above LKR **[To agree with both shareholders / කොටස්හිමියන් දෙදෙනා එකඟ විය යුතු]**, borrowing, related-party transactions, director appointments, salary above LKR **[To agree with both shareholders / කොටස්හිමියන් දෙදෙනා එකඟ විය යුතු]**, changes to business
- **Information rights** — monthly management accounts, bank statements, production/sales reports
- Anti-dilution
- Tag-along rights
- Liquidation preference (සමහර විට)
- **Founder vesting** — ඔබේ කොටස් වසර 3–4කට vest වීම
- Non-compete

### ඔබ ඉල්ලා සිටිය යුතුය:
- Day-to-day operational control (Managing Director role)
- **Milestone-based funding** නොවේ — committed funding
- Reasonable vesting / no clawback on delivered milestones
- Management salary / director fees from day one
- Pre-emption rights on new shares
- Drag-along protection
- **Dispute resolution** — arbitration (Colombo), governing law Sri Lanka
- **Valuation method** for exit — formula, not negotiation
