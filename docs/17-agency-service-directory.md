## 17.4 — 🏭 යන්ත්‍රෝපකරණ සහ ද්‍රව්‍ය සපයන්නන් | Equipment & material categories

**⚠️ මෙහි විශේෂිත සමාගම් නම් නොදක්වන්නේ — ඔබ විසින් වත්මන් quotation 3ක් ලබාගෙන තෝරාගත යුතු බැවිනි. නමුත් සෙවිය යුතු ප්‍රවර්ග:**

| ප්‍රවර්ගය | සෙවිය යුතු දේ |
|---|---|
| **Water treatment plant (RO systems)** | ශ්‍රී ලංකාවේ සවිකළ reference plants 3ක්; membrane brand; AMC |
| **Bottling monoblock** | Capacity, changeover time, spares, service engineer |
| **PET blow moulding** | Cavity count, preform compatibility, moulds included? |
| **PET preforms** | Virgin resin, food-grade certificate, g weight options |
| **Caps (PCO 1810/1881)** | Food grade, colour options, MOQ |
| **Labels / shrink sleeves** | Printing quality, food-safe inks, FCAU label compliance |
| **Chemicals** | Antiscalant, CIP caustic/acid, sanitiser — **MSDS + food grade** |
| **Lab equipment** | Calibration service, reagent supply |
| **Compressors (oil-free)** | Food-grade certification (ISO 8573-1 Class 0) |
| **Generators** | kVA, fuel efficiency, AMC |
| **Vehicles** | Refrigeration not needed but covered/clean body required for food |
| **Pallets & racking** | Food-grade, washable (plastic pallets recommended) |

**Quotation එකේ අනිවාර්යයෙන් තිබිය යුතු:** price (Incoterms), delivery time, installation & commissioning, training (days + no. of persons), warranty, spare parts list with prices, payment terms, references.
