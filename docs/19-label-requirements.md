# ලේබල් අවශ්‍යතා | Label Requirements

**නීතිමය පදනම / Legal basis:**
- **Food (Labelling and Advertising) Regulations No. 1 of 2005** — Food Act No. 26 of 1980 යටතේ
- **FCAU** විසින් අයදුම්පත සමඟ **ලේබල් නියැදි 2ක්** ඉල්ලයි
- **CAA** විසින් Consumer Affairs Authority Act No. 9 of 2003 යටතේ බලාත්මක කරයි

---

## 19.1 — ⭐ අනිවාර්ය ලේබල් අයිතම | Mandatory label elements

| # | අයිතමය | සටහන් |
|:--:|---|---|
| 1 | **නිෂ්පාදනයේ නම** | "බෝතල් කළ පානීය ජලය" / **"Bottled Drinking Water"** — හෝ "බෝතල් කළ ස්වාභාවික ඛනිජ ජලය" / **"Bottled Natural Mineral Water"** |
| 2 | **සෞඛ්‍ය අමාත්‍යාංශ ලියාපදිංචි අංකය** (Ministry registration number) | 🔴 අනිවාර්යයි — ලියාපදිංචිය ලැබුණු පසු |
| 3 | **SLS සහතික ලකුණ** (SLS Mark) + SLS අංකය (894 / 1038) | SLSI permit ලැබුණු පසු |
| 4 | **ජල මූලාශ්‍රය** (source of water) | උදා: "භූගත ජලය / Groundwater — Bandarawela, Badulla" හෝ "ස්වාභාවික උල්පත / Natural Spring" |
| 5 | **පිරිපහදු ක්‍රමය** (treatment method) | උදා: "Reverse Osmosis treated and Ozonated" |
| 6 | **Net quantity** | ml / L — SI ඒකක |
| 7 | **නිෂ්පාදකයාගේ නම සහ සම්පූර්ණ ලිපිනය** | සමාගම් නම + කර්මාන්ත ශාලා ලිපිනය |
| 8 | **Batch number / Lot code** | Traceability — වසර 2ක් වාර්තා තබාගන්න |
| 9 | **Manufacturing Date (MFD)** | |
| 10 | **"Best Before" / Expiry date** | Shelf life validation එකෙන් තහවුරු කරන්න |
| 11 | **ගබඩා කිරීමේ උපදෙස්** | "සිසිල් වියළි තැනක ගබඩා කරන්න; හිරු එළියෙන් ආරක්ෂා කරන්න" |
| 12 | **Barcode (EAN-13 / GTIN)** | GS1 Sri Lanka |
| 13 | **🔴 පොලිතීන් මුද්‍රාව (polythene seal) මූඩිය මත** | **සෞඛ්‍ය අමාත්‍යාංශ නීතියකි** — සෑම බෝතලයකම |
| 14 | **භාෂා** | සිංහල + දෙමළ + ඉංග්‍රීසි ත්‍රිත්වය නිර්දේශිත (සමහර අයිතම අනිවාර්ය) |
| 15 | **පාරිභෝගික hotline / සම්බන්ධතා** | නිර්දේශිත |

## 19.2 — තහනම් / වැළැක්විය යුතු | Prohibited & risky claims

- ❌ **ප්‍රතිකාර/සෞඛ්‍ය ප්‍රකාශ** — "වකුගඩු රෝගයට හොඳයි", "පිළිකා වළක්වයි" යනාදිය
- ❌ **නොමඟ යවන පින්තූර** — ජල මූලාශ්‍රය කඳු උල්පතක් නොවේ නම් කඳු/දිය ඇලි පින්තූර භාවිත නොකරන්න (ලංකාවේ මීට පෙර නඩු තිබේ)
- ❌ **"100% Pure"** වැනි තහවුරු කළ නොහැකි ප්‍රකාශ
- ❌ වෙනත් බ්‍රෑන්ඩ් එකකට සමාන නිර්මාණ (trademark infringement)
- ❌ "Natural Mineral Water" ලෙස නම් කිරීම — **සැබෑ ස්වාභාවික උල්පතක් නොමැති නම්** (SLS 1038 අවශ්‍යතා)
- ⚠️ **"Mineral Water"** යන වචනය භාවිතය — RO ජලයක් සඳහා "Bottled Drinking Water" නිවැරදියි

---

## 19.3 — ලේබල් නිර්මාණ ක්‍රියාවලිය | Label workflow

```
1. නම + ලෝගෝ නිර්මාණය → ⭐ Trademark search (NIPO) → Trademark application
2. ලේබල් නිර්මාණය (designer) — bottle shape mockups
3. ලේබල් නීති පරීක්ෂාව — නීතිඥ / QA / ආහාර තාක්ෂණ උපදේශක
4. ⭐ FCAU වෙත ලේබල් නියැදි 2ක් — අයදුම්පත සමඟ
5. ප්‍රින්ටර් proof + colour proof
6. මුද්‍රණය — food-safe inks, moisture-resistant film
7. Batch coding test (MFD/EXP/Batch legibility + adhesion)
8. Shrink sleeve / label application test on the line
9. ⭐ සුපිරි වෙළඳසැල් / retail listing requirements
   (සමහරු barcode, MRP display, language requirements ඉල්ලයි)
```

---

## 19.4 — විවිධ භාජන සඳහා | Per-container notes

| භාජනය | විශේෂ ලේබල් අවශ්‍යතා |
|---|---|
| **PET 250/500/1000/1500 ml** | සම්පූර්ණ ලේබලය; neck seal |
| **19 L / 5 gallon** | Handle tag / printed bottle + separate label; **"Refillable — return to supplier"**; bottle deposit info |
| **Glass (premium)** | සම්පූර්ණ ලේබලය; premium design |
| **Cartons / multi-packs** | Outer pack label — "Contains ___ × ___ ml"; barcode on outer pack |
| **Export labels** | ගැනුම්කරුගේ රටේ භාෂාව, ආනයන නීති, HS 2201, country of origin |

---

## 19.5 — ලේබල් පරීක්ෂණ ලැයිස්තුව | Pre-print checklist

- [ ] නිෂ්පාදනයේ නම නිවැරදිද? ("Bottled Drinking Water" vs "Natural Mineral Water")
- [ ] සෞඛ්‍ය අමාත්‍යාංශ ලියාපදිංචි අංකය ඇතුළත්ද?
- [ ] SLS Mark + SLS අංකය ඇතුළත්ද? (permit ලැබුණු පසු)
- [ ] ජල මූලාශ්‍රය නිවැරදිව විස්තර කර ඇත්ද?
- [ ] පිරිපහදු ක්‍රමය ඇතුළත්ද?
- [ ] Net quantity SI ඒකකවලින්ද?
- [ ] නිෂ්පාදක ලිපිනය සම්පූර්ණද?
- [ ] Batch / MFD / Best Before ඉඩ වෙන් කර ඇත්ද? (coder ස්ථානය)
- [ ] Barcode scannable ද? (GS1 verification)
- [ ] ත්‍රිභාෂා භාෂා අවශ්‍යතා සපුරා ඇත්ද?
- [ ] **Neck seal / polythene seal** සඳහා ඉඩ?
- [ ] Font size — නීතිමය අවම ප්‍රමාණයට වඩා විශාලද?
- [ ] Colour contrast — කියවිය හැකිද?
- [ ] Food-safe ink certificate?
- [ ] නීතිඥ/QA අත්සන?
- [ ] ⭐ **FCAU අනුමැතිය?**

---

> ✅ **තීරණය (2026-10-10):** අපේ නිෂ්පාදනය **"බෝතල් කළ පානීය ජලය / Bottled Drinking Water" (SLS 894)** වේ. උල්පතක් නොමැති බැවින් **"Natural Mineral Water"** හෝ **"Spring Water"** යන වචන **භාවිත කළ නොහැක.** 👉 [තීරණ වාර්තාව](21-decisions-and-assumptions.md)
