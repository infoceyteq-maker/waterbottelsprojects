## 16.6 — අවදානම් උපදේශන ක්‍රමය | How to use this register

1. **මාසිකව** ආයෝජකයා සමඟ සමාලෝචනය කරන්න
2. එක් එක් අවදානමට **වගකිවයුත්තෙකු (owner)** සහ **ඉලක්ක දිනයක්** ලබා දෙන්න
3. නව අවදානම් එකතු කරන්න; score යළි ගණනය කරන්න
4. Score 6+ වන ඕනෑම අවදානමක් **board agenda** එකට
5. මිලදී ගැනීමේ/ගිවිසුම් තීරණවලදී මෙම ලේඛනය **අනිවාර්ය කියවීමක්** කරන්න

**Score ගණනය:** P × I (1–3 × 1–3). 6–9 = 🔴, 3–4 = 🟠, 1–2 = 🟡
