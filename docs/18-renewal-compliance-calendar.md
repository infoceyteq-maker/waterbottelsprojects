## 18.5 — 📊 අනුකූලතා dashboard — නිර්දේශිත columns

`data/renewals.csv` ගොනුව Google Sheets වෙත ගෙන ගොස් මෙම තීරු එක් කරන්න:

```
Document | Authority | Issue Date | Expiry Date | Days Remaining |
Renewal Start Date (Expiry − 90 days) | Owner | Status | Fee |
Last Renewed | Reminder Sent (Y/N) | Notes
```

**සරල formula:**
- `Days Remaining` = `=Expiry_Date - TODAY()`
- **Conditional formatting:** <90 days → 🟡; <30 days → 🔴; <0 → ⛔ **නිෂ්පාදනය නවත්වන්න!**

## 18.6 — ⚠️ නොනැවතීමේ නීති | Do-not-miss rules

1. **FCAU ලියාපදිංචිය කල් ඉකුත් වුවහොත්** → බෝතල් ජලය නිෂ්පාදනය/විකිණීම **නීතිවිරෝධයි**. කර්මාන්ත ශාලාව වසා දැමිය යුතුය.
2. **Trade Licence කල් ඉකුත් වුවහොත්** → FCAU renewal කරන්න බැහැ + ප්‍රා.ස. දඩ.
3. **EPL කල් ඉකුත් වුවහොත්** → National Environment Act 23A උල්ලංඝනය; නඩු.
4. **EPF/ETF ප්‍රමාද වුවහොත්** → surcharge + ශ්‍රම දෙපාර්තමේන්තු ක්‍රියාමාර්ග.
5. **Annual Return ප්‍රමාද වුවහොත්** → දඩ; සමාගම strike-off ලැයිස්තුවට.
6. **SLS Mark permit කල් ඉකුත් වුවහොත්** → SLS ලකුණ ලේබලයෙන් ඉවත් කළ යුතුය (marketing හානිය).
